## Учебный проект Project_5
# *Разработка LMS-системы дли размещения полезных материалов и курсов с использованием DRF (Django REST framework).*

**LMS (Learning Management System)** — это система управления обучением, программная платформа для организации, 
автоматизации и контроля образовательного процесса. Она позволяет создавать, распространять и отслеживать обучающие материалы, 
контролировать прогресс учащихся, анализировать эффективность обучения и взаимодействовать с участниками.

## Цель проекта
+ Закрепление теоретических навыков на практике;

## Установка
Чтобы работать с проекта необходимо:
1. Загрузить проект в IDE через инструмент *'clone repository'* или команду `git clon`
   используя ключ: 
    - GitHub CLI: `gh repo clone L-Ev-Vi/Project_5` для работы из командной строки ОС;
    - или HTTPS: `https://github.com/L-Ev-Vi/Project_5.git`;


2. Выполнить настройку виртуального окружения *Poetry*
3. Установить зависимости проекта указанные в файле [pyproject.toml](pyproject.toml), выполнив команду `poetry install`;
4. Если ещё не установлена, то скачать БД [PostgreSQL](https://www.python.org/downloads/) для вышей ОС;


5. Выполнить установку PostgreSQL:
   - инструкцию по установке на [Windows](https://www.youtube.com/watch?v=TrDBb1zY2SM);
   - [macOS](https://www.youtube.com/watch?v=snLQ6GsxnLk);
   - [Linux](https://www.youtube.com/watch?v=FcTRbMFNdlU);
   

6. Если ещё не установлен, то скачать Redis для вышей ОС;
   - [Windows](https://github.com/microsoftarchive/redis/releases.);
   - macOS `brew install redis`;
   - Linux 
     - `sudo apt update` 
     - `sudo apt install redis-server`;


### ВАЖНО! Что нужно настроить!
#### Первичные настройки также включают в себя создание БД в ручном режиме. Для создания БД и работы данного проекта используется СУБД PostgreSQL.
#### Для создания БД в СУБД PostgreSQL используйте команду: CREATE DATABASE name_database(имя вашей БД)

- *`psql -U postgres`*
- *`CREATE DATABASE name_database(имя вашей БД)`*

#### Также в проекте представлен файл *[.env.sample](.env.sample)* который вам нужно переименовать в *.env* и указать в нём свои значения:
**Django**

- *SECRET_KEY = секретный ключ, используемый для криптографических подписей.*
- *DEBUG = режим отладки. Включен (True), Выключен (False)*

**Postgresql**

- *NAME = имя вашей базы данных.*
- *USER = имя пользователя PostgreSQL.*
- *PASSWORD = пароль пользователя PostgreSQL.*
- *HOST = адрес сервера базы данных.*
- *PORT = порт, на котором работает PostgreSQL, обычно 5432*

**Stripe**
- STRIPE_API_KEY = секретный ключ для доступа к платёжной системе "Stripe" https://stripe.com/

**Redis**

- CELERY_BROKER_URL = URL указывающий на брокера сообщений
- CELERY_RESULT_BACKEND = URL указывающий на расположение сервера для хранения результатов задач
- CELERY_TASK_TRACK_STARTED = флаг отслеживания выполнения задач. Включен (True), Выключен (False)

**Сервис отправки писем**
- EMAIL_HOST = адрес SMTP-сервера
- EMAIL_HOST_USER = адрес вашей электронной почты
- EMAIL_HOST_PASSWORD = пароль, сгенерированный в аккаунте вашей почты для доступа приложения к рассылке писем от вашего имени
- EMAIL_PORT = порт SMTP-сервера
- EMAIL_USE_TLS = включает использование TLS для шифрования соединения. Включен (True), Выключен (False)
- EMAIL_USE_SSL = включает использование SSL для шифрования соединения. Включен (True), Выключен (False)
- EMAIL_BACKEND = бэкенд для отправки писем

## Запуск проекта
**После клонирования репозитория и настройки виртуального окружения, выполняем следующие команды:**
- **1) устанавливаем необходимые зависимости если этого еще не сделали `poetry install`;**


- **2) применяем миграции (перед применением миграций не забудьте создать и настроить БД) `python manage.py migrate`;**

**Далее можно выполнить команды по созданию тестового урока и курса, а также создать администратора, 
модератора, пользователя и заполнить базу данных тестовыми платежами используя следующую команду:**
- **3)`python manage.py add_data` (Windows) - создание тестового урока, курса, администратора, 
модератора, пользователя и платежей**


- **4) В отдельном окне терминала в водим команду `redis-server` для запуска брокера Redis (перед запуском 
Redis не забудьте настроить подключение в файле *[.env.sample](.env.sample)* и [settings.py](config/settings.py))**

- **5) Для запуска обработчика в отдельном окне терминала введите следующую команду:**
   - macOS/Linux `celery -A config worker -l INFO`
   - Windows `celery -A config worker -l INFO -P eventlet`


- **6) Для запуска планировщик Celery beat в отдельном окне терминала введите следующую команду:**
   - Windows/macOS/Linux `celery -A config beat -l INFO -S django`
  

- **7) Для запуска веб-сервиса, в терминале командной строки введите одну из команд:**
  - **на Windows через *Terminal:* `python manage.py runserver`**
  - **на iOS через *a-Shell:* `python3 manage.py runserver`**
  - **на Linux через *Linux Terminal:* `python3 manage.py runserver`**

После успешного запуска программы вы увидите сообщение похожее на это:

*Django version 6.0.3, using settings 'config.settings'
Starting development server at http://127.0.0.1:8000/
Quit the server with CTRL-BREAK.*

**После чего можно перейти в HTTP-клиент "Postman" для тестирования URL запросов на сервере.**

Для остановки работы сервиса необходимо нажать комбинацию клавиш `Ctrl + C` после чего сервер остановится и веб-приложение, завершит свою работу.
Той же комбинацией `Ctrl + C` останавливается *Redis*, обработчик и планировщик.

Для запуска тестов и подсчета покрытия тестами запустите следующие команды:
- `python manage.py test`
- `coverage report -m`
